# Skippr Data Engineer (`sde`)

[![CI](https://github.com/skipprd/sde/actions/workflows/ci.yml/badge.svg)](https://github.com/skipprd/sde/actions/workflows/ci.yml)
[![Release](https://img.shields.io/github/v/release/skipprd/sde)](https://github.com/skipprd/sde/releases)


Skippr Data Engineer is the **`sde`** CLI. It is **not** `skippr` (that binary is Skippr Cloud only).

`sde init`, `sde connect`, `sde doctor`, `sde model`, `sde vector`, and `sde ask` live here. Discover and sync **shell out to `skipprd` on PATH**.

Docs: https://data-engineer.skippr.io

```bash
brew tap skipprd/tap
brew install sde skipprd
```

Or download linux x86_64 / darwin arm64 tarballs from [GitHub Releases](https://github.com/skipprd/sde/releases).
