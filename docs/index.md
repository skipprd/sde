# Skippr Data Engineer

**`sde`** is the Data Engineer CLI. Cloud `skippr` is a different product.

```bash
brew tap skipprd/tap
brew install sde skipprd
sde init
sde connect
sde doctor
sde model
```

Discover and sync invoke **`skipprd`** on PATH. Engine docs: [elt.skippr.io](https://elt.skippr.io).

Managed Cloud ELT: [skippr.io/elt](https://skippr.io/elt/).

**Source-available** under PolyForm Shield 1.0.0, not OSI open source.
